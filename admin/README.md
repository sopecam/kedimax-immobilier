# KEDIMAX — Administration

Cette branche prépare l'intégration du back-office KEDIMAX.

## Important

Le site public actuel reste inchangé. Le dossier `admin/` est développé séparément avant intégration sur `main`.

L'administration finale devra utiliser une authentification serveur et un stockage sécurisé. Aucun mot de passe ne doit être placé dans le HTML ou le JavaScript côté client.

## Modules prévus

- Authentification administrateur
- Tableau de bord
- Annonces immobilières
- Véhicules
- Motos
- Images
- Demandes clients
- Publication / brouillon
- Modification et suppression
